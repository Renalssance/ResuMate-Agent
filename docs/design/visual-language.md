# ResuMate · Milo 视觉语言

确认日期：2026-10-23。设计依据：[用户确认稿](./resumate-milo-approved.png)。

规范版本：v1.1，修订日期：2026-10-24。本版补齐按钮、响应式布局、间距与交互规则；属于后续界面实现依据，不表示所有页面已完成适配。

## 品牌与角色

主题：**ResuMate：你的招聘好伙伴**。以亲和的猫咪陪伴首次使用，以清晰的信息层级支持日常工作。

Milo（米洛）是一只暹罗猫形态的 3D 盲盒潮玩：奶油米色身体，可可棕重点色覆盖面部、耳朵、爪子和尾巴，蓝色眼睛。头身比约 1:1，圆润头部、蛋形躯干、短圆柱四肢、粗圆尾巴。哑光磨砂软胶质感，柔和散射光。**肚皮必须保持纯色，不得添加图案、标志或浮雕。** 不使用绿色身体，不使用真实毛发或高光塑料材质。可以手持简历道具。

虚构角色档案：昵称米洛；出生地灵感工作室；生日 10 月 23 日；性别不设定；好奇、耐心、有点呆萌；喜欢整理简历、发现闪光点。

字体使用本地系统字体：英文 Avenir Next，中文苹方、微软雅黑，回退 sans-serif。标题圆润厚重，正文清晰。首页标题自适应约 40–76px，章节标题 28–40px，正文 16–18px，辅助文字 13–14px。基础间距 8px；首页内容最大宽度 1200px；移动端保留 20px 边距。工作台按下文的内容类型确定宽度。

## 页面与交互

- `/`：公开首页，导航注册登录入口；主题、米洛和主要行动；文档解析、岗位匹配、面试准备；使用流程；角色介绍与结尾行动。
- `/login`、`/register`：独立表单，复用已有认证服务；提交中禁止重复操作；失败留在表单显示错误；成功进入 `/documents`。
- 首页顶部始终显示“登录”和“注册”入口，包括已登录状态；已登录时首屏主要行动显示“进入工作台”。工作台品牌链接返回首页，原有工作台路由保持有效。
- 公共页面与工作台共享品牌变量。工作台使用奶油底色、可可棕导航与主按钮、雾蓝辅助状态、12px 控件和 20px 卡片；保留业务信息布局。玻璃模式同步采用奶油、燕麦与雾蓝背景。

工作台账号信息与“退出登录”统一放在侧栏，设置页不再重复展示账号卡片。模型配置逐项展示名称、API 地址、API Key、输出 Token 上限和请求超时；缺失项分别提示，API Key 使用固定掩码，加载失败不标为未配置。退出后清除会话并返回首页；未登录访问设置时提示返回首页管理账号。

## 动效

首页首版采用轻微整体起伏和悬停回应，不自动播放强烈循环动作；`prefers-reduced-motion: reduce` 时关闭。设计稿中的眨眼摆尾、独立挥爪、翻阅和点头是后续角色动画方向，不能把整体位移动画宣称为已完成这些分镜。功能处理状态必须来自真实任务，不能用演示动画冒充进度。

## 工作台设计原则

工作台服务于整理简历、匹配岗位、准备面试与跟踪投递。每页应明确当前任务、下一步操作以及真实处理状态。品牌识别集中在首页、空状态与 Milo 任务气泡；正文、表单和记录列表保持安静，不为装饰添加编号、卡片嵌套或动画。

统一的是语义、层级和行为，不要求所有内容使用相同尺寸。以下规则覆盖工作台；首页保留已有展示字号、留白与胶囊按钮，共享品牌色、反馈及无障碍规则。

## 页面栅格与响应式

布局列是随容器伸缩的格子；间距单位是固定基准：1 格 = 8px，半格 = 4px。两者不得混用。页面最小高度铺满视口，纵向行数随内容增长，不固定总格数。

| 页面外壳 | 桌面 ≥1200px | 平板 768–1199px | 手机 <768px |
| --- | --- | --- | --- |
| 主内容布局列 | 12 列 | 8 列 | 4 列 |
| 内容左右最小留白 | 32px | 24px | 20px |
| 列间距 | 24px | 16px | 16px |
| 主要区块纵向间距 | 24px | 24px | 16px |
| 工作台导航 | 248px 侧栏 | 导航抽屉 | 导航抽屉 |

布局列从侧栏之外的内容区域计算。页面断点只决定外壳，内部组合按实际可用宽度折行，不能把 1200px 视口等同于 1200px 内容区。栅格列数不强制决定卡片数量。

宽度按任务确定：

- 首页最大 1200px；设置与资料编辑页面最大 1200px，居中。
- 投递记录、日历等数据页面使用侧栏之外的可用宽度，不套用首页上限。
- 简历正文、分析说明等连续阅读区域最大 48rem；位于大卡片中时左对齐，周围保留留白。
- 抽屉常规宽度 560px，上限为可用视口；手机全宽。确认弹窗常规 480px、复杂表单 640px，最大不超过视口减去两侧各 20px。

### 容器变化规则

以下宽度均指容器内部可用宽度；rem 阈值按默认 16px 字号理解，随文字设置伸缩。

| 内容类型 | 宽屏排布 | 折行条件与窄屏排布 |
| --- | --- | --- |
| 标题、筛选、主要结果 | 占满所在栅格 | 工具放不下则换到标题下方；保持 DOM 阅读顺序 |
| 同级双栏卡片 | 两栏等宽 | 内宽不足 40rem 时单栏；只有概览或比较卡片需要等高 |
| 主内容 + 辅助信息 | 约 2:1，即 12 列中的 8 + 4 | 内宽不足 56rem 时改为主内容在前、辅助在后 |
| 三张概览卡片 | 三栏等宽 | 每张至少 16rem 加列间距；空间不足降为两栏，再降为单栏；手机单栏 |
| 表单 | 短字段两栏，长字段通栏 | 两个字段各需至少 16rem，加 16px 间距；不足则单栏；手机单栏 |
| 投递记录 | 横向展示便于比较 | 所有信息列与操作无法容纳时改为纵向卡片：公司岗位、状态、时间、操作 |
| 日历 | 保留七列 | 窄屏单格只显示日期和简化事件标记，选中日期的完整事件在下方展示 |

API 地址、长备注、简历正文通栏；不同内容长度不强制拉齐高度。普通卡片跟随页面滚动；抽屉和弹窗超高时正文内部滚动、头尾操作可到达。关键内容不得通过整页横向滚动才能访问。

## 按钮语义、层级与位置

同一语义使用同一色系；强调程度由当前任务决定。一个操作区域仅一个最强调的提交动作。多行重复工具不使用同等强度的实心主按钮。

| 操作 | 外观 | 归属与位置 |
| --- | --- | --- |
| 保存、确认提交 | 可可棕底、白字 | 所属编辑区域底部右侧 |
| 开始分析、生成结果 | 可可棕底、白字 | 输入配置末尾的操作区；不强制放到整页底部 |
| 编辑 | 可可棕语义；卡片唯一主操作可实心棕，重复列表工具用棕字或浅棕底 | 对应卡片标题右侧或记录操作区 |
| 刷新、重新加载 | 白底、棕字、细描边 | 所影响区域标题栏右侧 |
| 取消、返回 | 白底、棕字、细描边 | 取消在保存左侧；返回属于页面导航，不等同于取消编辑 |
| 复制、查看、展开 | 低强调文字或图标按钮 | 紧邻对应内容 |
| 删除、清空 | 红字或浅红底；不可逆删除的最终确认使用红底 | 与常规操作适当分隔 |

保存 / 取消始终按“取消在左，保存在右”排列，整体右对齐。整页编辑共用一个底部操作区；局部编辑的保存只影响所在容器，操作区也放在该容器内。编辑入口在编辑期间由状态文案替代，避免重复入口。

手机窄屏可将取消和保存设为等宽，仍保留主次颜色；只有主操作时可占满一行。长编辑页使用吸底操作栏时，为正文预留其高度与安全区，软键盘弹出后最后一个字段和按钮仍可滚动到达。不可仅因动画未结束而阻止操作；保存请求进行中可以阻止重复提交。

“取消”丢弃本轮未保存编辑，“重置”恢复明确标注的初始值，“清空”删除当前输入，不可混用。不可逆删除才使用确认弹窗；不为每次普通操作增加确认。

| 工作台文字角色 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 页面标题 | 桌面 28/36px，手机 24/32px | 700 |
| 卡片标题 | 18/26px | 600 |
| 正文、输入内容 | 16/24px | 400 |
| 字段标签、列表内容 | 14/22px | 标签 600，内容 400 |

上述 px 是默认视觉基准；实现字体时使用可缩放单位，不锁死根字号。中文正文和按钮字距为 0，不人为插空格。首页大标题按现有品牌排版调整，不将其负字距套用到工作台正文。

## 表面、颜色与状态

- 页面底色奶油，正文 `#352B27`，次要文字 `#786B63`，主操作 `#63483E`，主操作悬停 `#4A342C`。雾蓝 `#7EAAC4` 主要用于插画和辅助底色，小字使用更深的现有信息色 `#527B94`。
- 工作台卡片圆角 20px，首页展示卡片 24px，状态标签胶囊形。内部内容优先用标题、留白和分隔线，不为每组信息增加一层卡片。
- 玻璃材质限于导航或浮层，正文、输入区使用稳定底色；不叠加多层半透明面板。玻璃不是状态，不用透明度变化表达保存是否成功。
- 信息与成功状态可以沿用现有雾蓝体系，但必须通过文字、图标区分；警告与危险使用现有对应色，不能只靠色相判断。
- 上传框保留纯奶油底、燕麦悬停；错误靠近相关字段，保存失败保留草稿。
- 首次加载使用加载状态；刷新保留已有内容与阅读位置，局部说明刷新中。空数据说明下一步动作，加载失败不展示为“没有数据”。
- Milo 气泡解释任务处理阶段，字段错误留在字段旁；同一结果不同时触发多个重复气泡或提示。成功文案与按钮动词一致，例如“保存”对应“已保存”。
- 图标沿用项目现有图标体系，统一线宽；纯图标按钮有可访问名称。所有交互元素有清晰键盘焦点。
- 需要高对比或减少透明效果时使用实底和明确描边；正文可读性优先于材质效果。

## 工作台动效行为

所有按钮必须有即时反馈，但不要求全部产生位移。反馈由按下、处理中和结果状态共同构成，不能等网络请求完成才回应。

| 场景 | 行为与时长 |
| --- | --- |
| 常规提交按钮 | 按下即开始轻微缩放，可到 0.98；过渡 100–160ms；松开恢复，不弹跳 |
| 密集工具、分页、日历格 | 即时或轻微底色反馈，不缩放信息区域；键盘操作不附加装饰位移 |
| 悬停 | 颜色或描边过渡 160ms；仅精确指针且支持悬停时启用 |
| 下拉菜单 | 150–200ms，从触发位置展开，退出回到相同来源 |
| 抽屉 | 200–240ms，从所在边进入并沿原路退出 |
| 弹窗 | 200–240ms，轻微缩放与透明度结合，不从零尺寸出现 |
| 刷新、筛选、日历切换 | 保持信息位置稳定，不让整块结果重复滑入；状态即时响应 |
| 保存处理中 | 保持按钮宽度稳定，显示真实忙碌状态；请求完成立即更新，不等待装饰动画 |

沿用现有 `--ease-out: cubic-bezier(0.23, 1, 0.32, 1)`；抽屉需要独立曲线时使用 `cubic-bezier(0.32, 0.72, 0, 1)`。连续旋转的忙碌图标使用线性节奏，不伪造百分比。

快速开关时从当前显示位置反向继续，不跳回起点；打开和关闭保持空间方向一致。普通点击交互优先使用可中断的 CSS 过渡。只有实际引入拖拽手势时才考虑承接速度的弹簧，不为本规范新增拖拽或动效库。

大面积运动优先使用 transform、opacity；局部颜色反馈允许小范围重绘。不动画化整页布局、卡片间距或大面积模糊，不使用 transition: all。普通信息卡片、已展示的列表不播放装饰性入场或逐项延迟。

`prefers-reduced-motion: reduce` 下去掉滑动、缩放与循环装饰，改用静态状态或短淡入淡出；忙碌状态始终提供文字，不依赖转动图标。动画不延迟焦点与操作响应。弹窗和模态抽屉打开时焦点进入、关闭后返回触发位置；非模态详情面板不无故锁住背景操作。

## 实施与验收边界

复用现有品牌、间距和缓动变量，集中定义角色与变体，避免页面另写一套按钮规则；不通过无差别全局选择器给所有元素增加动效。

本版已完成文字规范审查：按钮强调与语义分开、保存范围明确、页面与容器断点分开、固定高度改为最小高度，动效方向和打断行为有定义。未发现阻碍保存为设计依据的内部冲突。

后续实现时需用真实页面验证内容适配与交互：窄屏和文字放大是否裁切（失败则调整折行与最小尺寸）；保存、取消是否影响正确范围（失败则修正操作归属）；快速开关浮层是否跳跃或丢失焦点（失败则修正过渡及焦点管理）；玻璃模式下文字与状态是否清晰（失败则提高底色不透明度或调整文字色）。这些是实现验收，不宣称本次已完成浏览器验证。
