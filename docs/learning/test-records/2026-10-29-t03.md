## 验证目的与实际结果

| 检查 | 失败意味着什么；如何处理 | 结果 |
| --- | --- | --- |
| 创建持久 Run、快照 | 202 可能返回未持久化结果；修正事务提交位置 | 通过 |
| 重复键、同键不同参数、4 并发请求 | 重复任务或隐藏参数冲突；唯一约束+回滚读取 | 通过，两数据库各验证 |
| 双用户读取/取消/重试/回答及借用 Session/Resume | 越权；修正查询归属 | 通过 |
| 缺 token、body 伪造 owner | 认证可绕过或不符合错误协议；修正认证/请求校验 | 通过 |
| 同 Session 两个不同并发请求 | 多个活动 Run；条件占用同事务提交 | 通过，202 + 409 |
| queued/running/succeeded 取消 | 提前声称停止或破坏已完成产物；区别请求取消与实际停止 | 通过 |
| failed 重试、输入变化 | 错误状态重试或使用变更后的材料；保留快照、拒绝变化输入 | 通过 |
| 回答重放/冲突、拒绝审批 | 重复恢复或覆盖答案；一次性动作和状态校验 | 通过 |
| SQLite 取消/回答交错 | cancelled 被旧对象写回 queued；条件更新并回滚答案 | 通过 |

唯一 skip 是将 SQLite 专属读写交错放到 MySQL 参数下时主动跳过，因为 MySQL 行锁阻止这条具体执行顺序；不是缺少 MySQL 环境。T03 共 31 passed、1 skip，原有 244 项继续通过。
