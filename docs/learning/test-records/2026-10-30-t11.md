## 检查目的与运行环境

导出输入/派发测试检测错误 kind、混用输入、重复请求和误入模型；失败修 schema 与明确分支。生命周期检查检测主文档变化污染导出、打印持有写锁、取消/失权仍暴露下载、文件缺失冒充成功；失败修读取和提交边界。投递检查检测首次关联被覆盖、重复操作重写时间、原子创建留下半条记录以及普通 PATCH 替换历史材料；失败修条件更新与事务。

真实 PDF 检查固定中文字体、可提取正文、教育/独立要点/量化成果遗漏、清空字段复活、长文分页。任何失败修模板或运行依赖，不以模拟 bytes 代替结果。真实页面截图检查桌面/手机、长公司名、进行中、失败重试、确认版关联及历史快照；布局问题只修改受影响区域。

环境：Python 3.12.14、Playwright Python/Node 1.64.1、Jinja2 3.1.6、Chromium revision1248；Linux Debian Bookworm `fonts-noto-cjk=1:20220127+repack1-1`。本机复制安装同镜像的 Regular/Bold 字体。SQLite/临时 MySQL 9.6；浏览器使用真实 API、Redis、Celery，只有材料生成的模型是确定性替身，PDF 成功路径是真实 Chromium。

## 复现

```sh
RESUMATE_TEST_MYSQL_SOCKET=/tmp/resumate-mysql-t02/mysql.sock .venv/bin/python -m pytest backend/tests -q
npm --prefix frontend run test:unit
npm --prefix frontend test
npm --prefix frontend run build
PATH=/Applications/Docker.app/Contents/Resources/bin:$PATH npm run test:e2e
docker build -f deploy/worker.Dockerfile -t resumate-t11-worker .
PATH=/Applications/Docker.app/Contents/Resources/bin:$PATH RESUMATE_PDF_COMPOSE_TEST=1 .venv/bin/python -m pytest backend/tests/test_resume_export_compose.py -q -s
```

两个 Compose 测试使用独立开关；不应把默认skip计为通过。真实模型 smoke/语义评测仍由后续单元执行，本单元导出不调用模型。
