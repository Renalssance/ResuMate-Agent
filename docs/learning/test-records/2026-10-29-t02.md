## 检测目标与失败后的动作

- 重复 requestId/事件序号/interruptId/operationKey：如果能重复写入，补唯一约束，后续不得依靠内存去重。
- 跨用户 Session 关联、非法 Run 状态：如果能写入，修正复合外键/CHECK。
- 岗位来源去重：同用户同来源拒绝，不同用户及无来源粘贴允许，失败则修正 NULL 和唯一键语义。
- 事实修订、简历事实引用、投递快照：错误会使历史材料跟随新资料变化，修正版本存储。
- 旧库升级：如果旧数据丢失或 ORM 无法读取，修改增量脚本，不能继续 API 开发。
- 全后端回归：新模型注册可能影响已有 create_all 和投递接口，失败先定位模型/升级对旧路径的影响。
