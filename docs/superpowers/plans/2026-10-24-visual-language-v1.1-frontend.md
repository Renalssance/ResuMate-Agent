# 视觉语言 v1.1 前端全面优化实施计划

> 执行方式：使用 executing-plans 逐项实施，在本会话按依赖顺序推进。任务状态必须区分待实施、已实现、已验证；不能以全局 CSS 已修改代替逐页验收。

**Goal:** 将网页全部路由、全部 Vue 组件、公共样式及插件侧栏按 v1.1 统一，并保留原有业务功能。

**Architecture:** 以现有 Vue 模板、CSS 类和品牌变量为基础，先修正共享样式的定义来源，再逐页修正语义与布局。现有小组件继续复用；不新增通用组件框架，不用追加一大段高优先级覆盖样式掩盖原规则。

**Tech Stack:** Vue 3、TypeScript、Vue Router、Pinia、Vite、CSS；插件侧栏为 HTML/CSS/JavaScript。

**Spec:** [视觉语言 v1.1](../../design/visual-language.md)。本文件是实施计划，不代表代码优化已完成。

> 2026-10-24 执行更新：T1–T8代码与网页关键验收已完成，T9侧栏代码/静态预览/现有测试通过，真实扩展运行待验证。逐对象状态、截图与限制见[实施验收记录](../../design/visual-language-v1.1-implementation-review.md)。下方任务细项保留原计划文本，不以其复选框代替验收记录。

## 全局约束

- 保留已确认的 Milo 资产、系统字体和奶油 / 可可棕 / 雾蓝品牌方向。
- 布局列为 12 / 8 / 4 列，页面断点为 1200px、768px；容器折行按实际可用宽度。
- 1 间距格 = 8px，半格 = 4px；手机页面左右留白 20px。
- 标准控件最小高 44px，工作台控件圆角 12px、卡片 20px；首页展示卡片 24px。
- 保存 / 取消在所属编辑区底部右对齐，取消在左、保存在右；刷新在所属区域标题栏。
- 请求状态来自真实业务；保存失败保留草稿，刷新保留已有内容与阅读位置。
- 普通信息卡片不播放装饰入场，密集工具不缩放；减少动态效果时保留文字反馈。
- 不更改 API 协议、数据结构、权限、匹配算法、自动填表引擎。必要的 UI 状态修复限于对应功能。
- 当前工作区已有大量未提交修改；在当前文件基础上增量修改，不 reset、不覆盖用户改动、不自动提交现有全部工作。
- 不安装新字体、动效库或组件库。只有实现确有需要才提取小型共享逻辑。
- 每项检查先说明能发现什么失败、失败后如何调整。纯样式不新增镜像 CSS 字符串的测试。
- “全部审查”不意味着每个文件都要改：符合规范的组件记录保留理由；未挂载的组件不能冒充页面已验证。
